# Number Analysis Tool

## Overview

Number Analysis Tool is a beginner-friendly Python project that allows users to enter multiple numbers and analyze them. The program finds the largest number, smallest number, total sum, and average of the entered numbers.

## Features

- Accept multiple numbers from the user
- Store numbers in a list
- Find the largest number
- Find the smallest number
- Calculate the sum of all numbers
- Calculate the average

## Technologies Used

- Python

## Concepts Covered

- Variables
- Data Types
- Lists
- Loops
- User Input
- Built-in Functions
